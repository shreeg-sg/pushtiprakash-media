================================================================================
FOLDER: src/assets/mock/chapters/
PURPOSE: Individual Chapter Transcripts & Optional Chapter Images
================================================================================

1. FOLDER STRUCTURE
-------------------
src/assets/mock/chapters/
  └── <book_id>/
        ├── <chapter_id>.json
        └── ...

2. SAMPLE JSON (src/assets/mock/chapters/my_book/ch_01.json)
------------------------------------------------------------
{
  "id": "ch_01",
  "bookId": "my_book",
  "images": [
    "images/ch_01_art.jpg"
  ],
  "transcript": {
    "en": "Full English chapter text here...",
    "hi": "यहाँ पूरा हिंदी पाठ लिखें...",
    "gu": "અહીં સંપૂર્ણ ગુજરાતી પાઠ લખો..."
  }
}

3. STEP-BY-STEP FOR NEW TENANT
------------------------------
Step 1: Create a subfolder matching your exact book "id" (lowercase).
Step 2: Create one <chapter_id>.json per chapter with "transcript" keys
        matching your enabled language codes in supportedLanguages.json.
Step 3: Make sure "contentUrl" in src/assets/books/<book_id>.json matches
        "mock/chapters/<book_id>/<chapter_id>.json".
