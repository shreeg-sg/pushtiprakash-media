================================================================================
FOLDER: src/assets/mock/
PURPOSE: Master Runtime Configuration Files for Your White-Label App
================================================================================

1. FILES IN THIS FOLDER
-----------------------
1) app_identity.json         -> App name, logo/watermark paths, developerCredit, theme colors
2) auth_config.json          -> Login toggle, Supabase URL/key, 30-day expiry, Unique ID mode
3) supportedLanguages.json   -> Enabled languages & TTS locales (hi-IN, gu-IN, en-IN)
4) ui_translations.json      -> All UI & Login screen labels per language
5) books.json                -> Lightweight book catalog (points to books/<book_id>.json)
6) updateBannerMessage.json  -> Sticky dashboard banners (date-based, NEW badge, deep links)
7) about_info.json           -> Organization description, email, website & feedback links
8) notification_schedules.json -> Local mobile reading reminders
9) advertisement.json        -> Sticky bottom ad carousel settings

3. STEP-BY-STEP FOR NEW TENANT
------------------------------
Step 1: Update app_identity.json with your app name, colors, and mediaBaseUrl.
Step 2: Configure supportedLanguages.json (at least one language isEnabled: true).
Step 3: Configure auth_config.json (set enabled: false to disable login).
Step 4: Add books to books.json and chapter lists under src/assets/books/.
Step 5: Validate all JSON files before pushing to GitHub / CDN.
